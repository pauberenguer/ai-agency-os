Generate the professionally designed HTML audit report without converting to PDF.

This is the same HTML generated by /generate-pdf but skips the Chrome conversion step.
Useful when:
- Chrome is not available on the system
- The user wants to customize the HTML before converting
- The user wants to open in a browser and use Print → Save as PDF

Follow the pdf-report skill to generate the complete HTML file with all:
- SVG gauge charts for scores
- Color-coded issue severity cards
- CSS bar charts for competitor comparison
- Timeline roadmap visualization
- Professional tables with alternating rows

Save to: `reports/{business-name-slug}-seo-audit-{date}.html`

Tell the user they can:
1. Open the file in any browser to view
2. Use File → Print → Save as PDF for manual conversion
3. Customize colors, add their logo, or adjust styling before converting
