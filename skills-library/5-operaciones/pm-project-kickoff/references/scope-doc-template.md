# Scope Doc Template

See `scope-creep/references/scope-doc-template.md` for the full template
and guidance on writing a good scope_doc.

The scope_doc written at kickoff becomes the baseline for all scope
detection during the project. The scope-creep skill reads it directly.

Quick checklist before saving the scope_doc:

- [ ] Every contracted deliverable is listed explicitly
- [ ] Page/deliverable count is a specific number
- [ ] Revision rounds are a specific number
- [ ] Common exclusions are listed (e-commerce, booking, blog, etc.)
- [ ] Client assumptions are listed (what they must provide)
- [ ] Timeline milestones are included

If any of these are missing, the scope_doc is incomplete.
Do not start the project until it's complete.
